## Q3. 시장 분석

### TAM / SAM / SOM

| 구분 | 규모 | 설명 |
|------|------|------|
| TAM | ₩12,000억+ | 국내 전체 숙박 시장 중 커플/2인 단기 여행 숙박 수요 |
| SAM | ₩600억~800억 | 인천·영종도 권역 에어비앤비·단기 렌탈 커플 숙박 시장 |
| SOM | ₩30억~60억 | 커플 전용 큐레이션 채널로 현실적 공략 가능한 규모 |

### 핵심 트렌드 5개 요약

1. **오션뷰 감성숙소의 SNS 검증 문화** — 숙소 선택 기준이 "뷰와 사진"으로 이동
2. **가성비+프리미엄 동시 추구** — "저렴하면서도 호텔급 퀄리티" 요구
3. **재방문율이 높은 "루틴 여행지"화** — 수도권 1시간, 분기마다 방문하는 힐링지
4. **셀프웨딩·기념일 촬영지 수요** — 스튜디오 대신 에어비앤비 공간 활용 급증
5. **체크인/아웃 유연성 수요 폭발** — 6건+ 불만으로 업계 1위 페인포인트

### 덜 공략된 기회 5개 요약

1. **욕실 프라이버시 완성형 숙소** — 블라인드 설치(10~30만원)로 프리미엄 차별화
2. **어메니티 풀패키지 표준화 + 정보 선제 공개** — 전환율 10~15% 개선 추산
3. **레이트체크아웃 무료 제공의 가격 전략화** — 재방문 LTV 기반 손익분기 1~2 사이클
4. **플랫폼 외 커플 전용 큐레이션 채널 구축** — 영종도 판 큐레이션 계정 공백
5. **주변 액티비티 번들링** — 레일바이크·갯벌·맛집 코스 패키지화, 원가 거의 제로

## 핵심 인사이트 종합

### 이번 주 최우선 실행 3가지

1. **욕실 블라인드 즉시 설치** (5~10만원 투자, 별점 방어 즉각 효과) — 3개 후기에서 반복 지적된 욕실 프라이버시 문제가 별점 하락의 가장 직접적 원인
2. **레이트체크아웃 무료화 + 리스팅 제목 명시** — 6회+ 불만으로 업계 최다 페인포인트. 무료 전환 시 리뷰 차별화 즉시 반응, 재방문율 기반 LTV 회수 가능
3. **어메니티 목록 리스팅 상단 배치 + 세면도구 정보 명시** — 기범(⭐3) 사례처럼 정보 비대칭이 별점 3점으로 직결. 1~3만원/박 비용으로 리뷰 품질 즉각 개선
