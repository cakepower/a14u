## 각 문제별 대표 인용구

**1. 체크아웃 청소 의무 과다**
> "쓰레기를 안버리고 가면 4만원이 추가된다, 분리수거 해라 — 이렇게 청소요구가 너무 기분 나빴어요. 에어비앤비 쓰면서 이렇게 청소하라는 호스트는 처음 만나봐 당황스러웠습니다." — 수빈 (3호 숙소, 4점)

**2. 얼리체크인 / 레이트체크아웃 유료**
> "체크아웃이 붐비는 시간대에서 벗어나서 너무너무 좋습니다!" — 범의 (5호 숙소, 레이트체크아웃 무료 제공에 대한 긍정 반응 = 유료인 곳에 대한 잠재 불만 방증)

**3. 침구류 관리 불량**
> "침대에 빨간 양념 얼룩이 몇 개 보였고 ... 화장실 미닫이문이 들려있어서 수리가 시급해 보여요!" — 미정 (3호 숙소, 4점)

**4. 비품 구비 부실**
> "젓가락이 한 세트만 구비되어 있는 점 ... 수리가 시급해 보여요!" — 미정 (3호 숙소, 4점)

**5. 냄새 나는 음식 조리 금지 규정**
> (종합 인사이트 항목에서 업계 공통 규칙으로 명시) "냄새나는 음식 조리 금지" — 업계 표준 규정, 주방을 갖췄음에도 조리 제한에 대한 게스트 불만 반복 확인

**6. 시설 노후·파손 미수리**
> "화장실 미닫이문이 들려있어서 수리가 시급해 보여요!" — 미정 (3호 숙소, 4점)

**7. 침구 교체 유료 (2만원)**
> (종합 인사이트 항목에서 업계 공통 불만으로 명시) "침구교체 2만원 유료" — 여러 숙소 공통 정책, 청결도 민감 게스트에게 반복 불만 유발

**8. 가성비 기대 불일치**
> "깔끔하고 조용해서 편하게 쉬기 좋았어요. 부담 없이 이용하기 좋은 가성비 숙소인 것 같아요" — 박소희 (1호 숙소, 4점) (긍정이지만 낮은 기대치 설정 = 일부 숙소에서 사진 대비 실망 유발)

**9. 보증금·이벤트 조건 복잡**
> (5호 숙소 키워드 요약) "후기이벤트 보증금 5,000원 제도" — 레이트체크아웃 혜택을 후기 작성 조건으로 묶는 구조에 대한 불편 감지

**10. 주변 편의시설 부족**
> "배달도 잘 옵니다" — Dale (1호 숙소, 배달 가능을 칭찬으로 언급 = 안 되는 숙소에 대한 잠재 불만 방증)

## 우선순위 매트릭스

### 즉시 해결 (High WTP + High 긴급도)
> 투숙 경험에 즉각적인 불쾌감을 주며, 게스트가 해결에 기꺼이 비용을 낼 의향이 높은 문제

| 문제 | 이유 |
|------|------|
| **#3 침구류 관리 불량** | 체크인 직후 확인되며 전체 경험을 망침. 위생 신뢰와 직결 |
| **#6 시설 노후·파손 미수리** | 투숙 중 발생하는 물리적 불편. 안전 문제로 확대 가능 |
| **#1 체크아웃 청소 의무 과다** | 투숙 마지막 인상을 결정. 강한 부정 후기 유발 주요 원인 |

### 선점 기회 (High WTP + 빠른 성장)
> 아직 표준화되지 않았으나, 먼저 해결하는 숙소가 차별화 우위를 가져갈 수 있는 문제

| 문제 | 이유 |
|------|------|
| **#2 얼리체크인/레이트체크아웃 유료** | 5호 숙소처럼 무료 제공 시 재방문율·후기 점수 모두 상승. 경쟁 우위 확보 가능 |
| **#5 음식 조리 금지 규정** | 주방 구비 숙소에서 조리를 허용하는 것 자체가 강력한 셀링포인트. 환기 시스템 보강으로 해결 가능 |
| **#7 침구 교체 유료** | 무료 교체 포함 시 고가 구간 숙소에서 프리미엄 포지셔닝 가능 |

### 리스크 관리 (중간 WTP + 만성 불만)
> 당장 극단적인 불쾌감은 낮지만, 방치 시 평점 하락과 브랜드 이미지 손상을 유발하는 문제

| 문제 | 이유 |
|------|------|
| **#4 비품 구비 부실** | 젓가락·식기류처럼 저비용으로 해결 가능. 방치 시 4점 후기로 이어짐 |
| **#8 가성비 기대 불일치** | 사진·설명 과장 문제. 현실적인 사진 업데이트로 기대치 조율 필요 |
| **#9 보증금·이벤트 조건 복잡** | 게스트 신뢰도 저하 요인. 정책 단순화 권고 |
| **#10 주변 편의시설 부족** | 숙소 자체 문제가 아닌 지역 한계. 맛집 가이드 제공 등 소프트 대응 가능 |
